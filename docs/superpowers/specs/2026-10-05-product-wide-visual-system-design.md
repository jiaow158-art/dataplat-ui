# 东鹏问数全站视觉统一设计

## 目标

将已确认的“雾白玻璃·东方科技”视觉系统扩展到登录、AI 问数、经营事件中心、事件详情、我的关注和管理后台。统一品牌表达与基础交互，同时保留不同页面最适合其任务的结构，不修改核心业务逻辑。

## 共用设计系统

- 暖灰雾白画布、墨蓝主文字、灰蓝辅助文字。
- 蓝色表示主行动和进度，珊瑚红表示重大异常或危险操作，琥珀表示关注，青绿表示健康或完成。
- 卡片采用半透明白、12–16px 圆角、低扩散阴影与克制的背景模糊。
- 统一按钮、输入框、下拉框、筛选、表格、徽标、加载、错误和空态。
- 所有交互控件具备 hover、focus-visible、active、disabled 状态。
- 页面进入动效保持一次性、短时和错峰；支持 `prefers-reduced-motion`。

## 应用外壳与导航

- 桌面端保留完整侧栏、经营导航、会话列表、管理入口与用户操作。
- 移动端采用紧凑顶栏和可展开导航，不依赖无标签图标表达主要功能。
- 当前页面、当前会话与未读/异常状态使用一致的选中和语义色规则。

## 页面设计

### 登录页

以轻量品牌门户呈现：雾白光影背景、明确品牌标识、单一登录卡。保留用户名、密码、提交中、错误提示和自动填充行为，不增加未经提供的营销文案。

### AI 问数

采用专注型对话工作台。标题与会话状态形成轻量页头，历史内容保持连续阅读；问题、运行过程、答案、失败重试、反馈与报告预览共享统一的状态层级。输入区固定于内容底部，移动端不遮挡最后一条消息。

### 经营事件中心

采用高密度数据控制台。筛选区吸顶，统计摘要保持快速扫描；桌面使用表格，手机转换为事件列表卡。打开详情、继续分析和筛选逻辑保持不变。

### 事件详情

采用分析报告式阅读结构。顶部集中呈现返回、事件等级、持续时间、数据日和状态；正文按执行摘要、事实、归因、趋势与对象、状态、建议、关联事件和追问顺序展开。

### 我的关注

桌面保留关注对象与关注动态双栏，移动端转为单列。增加一致的加载、空态和失败表现；新增、取消关注和全部已读行为保持不变。

### 管理后台

管理壳和六个子页统一页头、Tab、表格、筛选、表单、分页、空态和危险操作样式。桌面保持信息密度，窄屏允许合理横向滚动，不改变权限与跨页跳转。

## 技术边界

- 不修改 API、数据模型、权限判断、SSE、状态机或业务回调。
- 优先复用 CSS token 和轻量公共样式，不引入新 UI 框架。
- 只在表现层拆分确有复用价值的组件；不进行无关重构。
- 保留现有中文文案与业务术语，除非为可访问性补充标签。

## 验收

- 现有构建与测试通过。
- 桌面、平板、手机断点无不可达功能、遮挡或关键溢出。
- 键盘焦点、加载、错误、空态、禁用与 reduced-motion 均可用。
- 登录、导航、问数、事件查看/追问、订阅和管理操作的核心路径保持不变。
- 最终进行机械设计检测、浏览器截图检查和独立代码 review。
